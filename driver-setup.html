NWTB Driver Setup

Permanent setup page for Driver View + background GPS on iPhone and Android.

Checking your phone…Preparing the correct setup.
DETECTING
No NWTB phone app required. NWTB Driver remains web based. The free Traccar Client handles background GPS while Google Maps is in front.
1. Install Traccar Client
This is the background GPS helper. It is free and already published for iPhone and Android.
INSTALL TRACCAR CLIENT
After installation, return to this page and continue with Step 2.
2. Connect this phone to NWTB
Enter the driver's 4-digit employee number. NWTB creates a private device ID for this phone; the employee number itself is not used as the tracking password.
Traccar will open and show a configuration confirmation. Tap OK / Confirm. Allow location access when the phone asks. On iPhone, enable Precise Location and allow background/Always location when offered. On Android, allow background location and keep the tracking notification enabled.
3. Start background tracking
After Traccar is configured, use this button to start its GPS service. The phone may ask for location permission the first time.
Once tracking is started, you can switch to Google Maps for turn-by-turn directions. NWTB Dispatch should continue receiving the phone's location.
4. Open NWTB Driver
Use the normal NWTB Driver page for route stops, pause/resume, delivery status and Google Maps navigation.
OPEN NWTB DRIVER
1
Select the driverThe Driver page remembers the last selected driver on the phone.
2
Start the assigned routeDispatch links the Traccar location to the driver's current PLANNED/ACTIVE route.
3
Open Google MapsTraccar remains responsible for GPS in the background while navigation is on screen.
4
Finish the routeLive Drivers only shows GPS tied to a current PLANNED or ACTIVE route.
Troubleshooting
If the truck becomes STALE, check that Traccar Client is still running, location permission has not been removed, battery optimization is not blocking the app, and the driver's route is still PLANNED or ACTIVE.
