NWTB Driver Setup

One QR code for NWTB Driver + background GPS on iPhone and Android.

Checking your phone…Preparing the correct setup.
DETECTING
Single QR setup. Drivers can find themselves by typing their name or enter their 4-digit employee number. NWTB Driver stays web based; Traccar Client handles background GPS.
1. Install Traccar Client
This free helper keeps sending GPS while Google Maps is in front or the NWTB browser page is in the background.
INSTALL TRACCAR CLIENT
If Traccar is already installed, skip to Step 2.
2. Find your driver profile
Start typing your name for autofill, or enter your 4-digit employee number. Tap your name if a list appears.
Traccar will open and ask you to confirm the NWTB configuration. Tap OK / Confirm. Then allow the strongest location permission available. On iPhone keep Precise Location on and allow background/Always access when offered. On Android allow background location and keep the tracking notification enabled.
3. Start background tracking
After configuration, start the Traccar GPS service.
After it starts, Google Maps can stay on screen while NWTB Dispatch continues receiving the location.
4. Open NWTB Driver
Use the normal Driver View for assigned route, stops, pause/resume, delivery status and Google Maps navigation.
OPEN NWTB DRIVER
1
Select your driver nameThe Driver View remembers the last selected driver on that phone.
2
Start the assigned routeLive GPS attaches to the driver's current ACTIVE route, or PLANNED route if it has not started yet.
3
Open Google MapsTraccar continues sending GPS in the background.
4
Finish the routeLive Drivers only displays drivers linked to current PLANNED or ACTIVE routes.
Troubleshooting
If the truck becomes STALE, verify Traccar tracking is ON, location permissions are still enabled, battery optimization is not blocking the app, and the route is still PLANNED or ACTIVE.
Permanent QR destination: this page stays the one QR target. We can change setup behavior later without reprinting the QR code.
